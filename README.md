# محفظة مشاريع وفرص منصة إحسان

مستودع تشغيلي للمحفظة النهائية التفاعلية، ويضم:
- ملف PDF تفاعلي للمحفظة.
- دراسات Word للفرص الـ96.
- نموذج تقرير الإغلاق.
- المصدر HTML وبيانات الفرص.

> هذه وثيقة عمل داخلية لإعداد مشاريع قابلة للتقديم عبر فرص منصة إحسان والمانحين، وليست وثيقة صادرة عن منصة إحسان.
