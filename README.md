# محفظة يدوم للمشاريع التنموية | YADOOM

الإصدار 3.0 — وثيقة عمل مستقلة لتطوير المشاريع والمبادرات والفرص التنموية غير الربحية.

## المحتوى
- 96 فرصة تنموية من البيانات الأصلية.
- 80 مشروعًا مطورًا.
- 176 بطاقة مشروع وفرصة.
- 11 نموذج Word لكل بطاقة، بإجمالي 1,936 مستندًا، ضمن مجلد docs.
- دفتر عمل للمشاريع بصيغة Excel.

## الواجهة
تستند الواجهة إلى ملفات index.html وyadoom.css وyadoom.js، وتقرأ بيانات المحفظة من data/cards.json والفهرس من data/templates.json.

يدعم الموقع البحث والتصفية، وصفحات التفاصيل، وحزم النماذج، وتصدير المسودات، وفحص الجاهزية. تُحفظ المسودات والتقييمات داخل المتصفح فقط.

## النشر
تُدار نسخة YADOOM على فرع yadoom-v3، ويجري نشرها في مشروع Vercel المستقل yadoom المرتبط بالنطاق yadoom.alalmaiesa.site. لا يغيّر هذا الفرع الموقع الأصلي على main.
