# محفظة مشاريع وفرص منصة إحسان

محفظة تفاعلية لإعداد وإدارة مشاريع الجمعيات الأهلية المرتبطة بفرص منصة إحسان والمانحين.

- 96 فرصة في بنك الأفكار.
- 80 مشروعًا مطورًا في الملحق.
- 176 بطاقة إجمالًا.
- 11 نموذج Word لكل بطاقة.
- 1,936 نموذج Word يتم توليدها آليًا عبر GitHub Actions.
- PDF تفاعلي يربط كل نموذج بمساره داخل المستودع.

## المراحل
- 🟢 الفكرة: بطاقة الفكرة، دراسة المشروع، ميثاق المشروع.
- 🟡 التحقق: معايير الاستحقاق، البحث الاجتماعي.
- 🔵 التنفيذ: مقارنة العروض، محضر الاستلام، التقرير المرحلي، سجل المخاطر.
- 🟣 الإغلاق: تقرير الإغلاق، قائمة الأدلة.

## GitHub Pages
فعّل Pages من Settings > Pages واختر **Deploy from a branch** ثم `main` و`/(root)`.

الرابط المتوقع: https://alalmaiesa-glitch.github.io/ehsan-project-portfolio/

> الوثيقة أداة عمل داخلية وليست صادرة عن منصة إحسان، ويجب التحقق من توافر الفرصة والضوابط وقت التقديم.
